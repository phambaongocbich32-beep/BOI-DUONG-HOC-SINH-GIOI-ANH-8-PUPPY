# Elite English 8

Web bồi dưỡng học sinh giỏi Tiếng Anh lớp 8 (theo sách Global Success): từ vựng, ngữ pháp theo chuyên đề, bài tập có chấm điểm và giải thích.

## Chạy web
- Mở trực tiếp `index.html` bằng trình duyệt, hoặc
- Bật GitHub Pages: Settings > Pages > Deploy from a branch > `main` / `(root)`.

Toàn bộ web nằm trong một file `index.html`. File `.nojekyll` báo GitHub Pages không xử lý bằng Jekyll.
